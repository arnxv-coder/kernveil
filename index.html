Findings you can actually understand

Every finding is written for a founder or generalist first, not for a dedicated security team. Here is an example from the demo workspace.

CriticalOpen

Publicly exposed storage resource

Affected asset · prod-web-01 · us-east-1 / acme-retail-primary

Open in demo

What was detected

The storage resource acme-retail-primary allows public read access. Its access-control list grants access to AllUsers, and the resource is reachable from the internet.

Why it matters

This resource contains backup data for customer orders. Anyone with internet access could read it. There is no evidence the data has been accessed, but the exposure is open right now.

Recommended next step

Restrict the access-control list to the application role that owns the resource, verify the change, then re-check for public access.

Evidence

ACL urn:acme:storage:acme-retail-primary AllUsers:READ
